# Omar Medhat Portfolio

Primary site is the curated HTML design in `public/design.html` (Bricolage Grotesque / Inter / JetBrains Mono / IBM Plex Sans Arabic).

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).
