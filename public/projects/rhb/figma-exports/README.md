# How to export RHB Figma frames for the portfolio

Drop PNG/JPG exports into this folder, then tell me — I'll wire them into the RHB card + case study.

## Best method (recommended)

1. Open **RHB - Website** in Figma
2. Zoom out / search for frames with `-REDESIGN` in the name
3. Select the frames you want (multi-select with Shift), e.g.:
   - Homepage / Desktop-1440 (LTR)
   - CorporateStays-REDESIGN / Desktop-1440
   - GrowWithRHB-REDESIGN / Desktop-1440
   - BabAlsalam / Landing-REDESIGN / Desktop-1440
   - One mobile (375) frame per page if you want mobile shots
4. In the right panel → **Export**
   - Format: **PNG**
   - Size: **2x** (or 1x if files get huge)
5. Click **Export [N] layers**
6. Save into:
   `D:\Freelance\omar-medhat-portfolio\public\projects\rhb\figma-exports\`

### Suggested filenames
- `homepage-desktop.png`
- `corporate-stays-desktop.png`
- `grow-with-rhb-desktop.png`
- `bab-alsalam-desktop.png`
- `homepage-mobile.png` (optional)

## Faster batch method

1. Select a parent frame / page
2. Right-click → **Copy/Paste as** → **Copy as PNG** (single frame), or use Export as above for many
3. Or install the free **"Export to Zip"** / use Figma's bulk export
